- **Fixed: `/devagent:stuck` writes the same STUCK header as every other writer (#909).** It no longer fails with `last_good: unbound variable` (exit 1, nothing marked or written) when no earlier step is done. `stuck.sh` and `checklist-stuck.sh` now both write the header through `stuck_write` in `scripts/lib/checklist.sh`: `Last good:   <N> <name>`, or `Last good:   (none)` when there is none (the line is always present), and `Created:` in `date -Iseconds` form with its zone. Before, `stuck.sh` wrote `Last good:   step <N> <name>` and a zoneless `%Y-%m-%d %H:%M`; on a revised checklist it now walks as `checklist-stuck.sh` and `hold.sh` do, per step number with the active revision block first. `checklist-stuck.sh`'s output is unchanged. STUCK files already on disk are kept as written, and every reader still accepts both old forms.
